# Recurring Spend Insight Card Spec

작성일: 2026-05-20  
기능 slug: `recurring-spend-insight-card`  
기능 크기: `medium`  
상태: draft

## 목적

홈 첫 화면에서 `이번 달 반복적으로 나가는 돈`을 가장 먼저 보여주는 인사이트 카드를 만든다.

이 카드의 목표는 단순 요약이 아니다.  
사용자가 앱을 열었을 때 `내 돈이 어디서 반복적으로 빠지고 있는지`를 3초 안에 이해하게 만드는 것이 목표다.

## 문제 정의

현재 대시보드는 월간 수입/지출, 최근 거래, 예산 상태까지는 보여주지만, 자동기입형 앱이 줄 수 있는 가장 강한 첫 보상은 부족하다.

사용자는 아래 중 하나를 빠르게 알고 싶어한다.

- 어떤 돈이 매달 굳어져서 빠져나가는지
- 줄일 수 있는 후보가 무엇인지
- 이번 달 압박의 원인이 어디인지

이 질문에 가장 잘 답하는 것이 반복지출 인사이트 카드다.

## 사용자 변화

기존:

- 이번 달에 얼마 썼는지 본다
- 최근 거래를 훑는다
- 예산을 넘었는지 확인한다

변경 후:

- 반복적으로 나가는 돈 총액을 먼저 본다
- 상위 반복지출 항목을 바로 이해한다
- 새로 생긴 반복성 지출이나 늘어난 항목을 빠르게 인지한다

## 범위

이번 기능에서 포함하는 것:

- 반복지출 총액 계산
- 상위 항목 3개 노출
- 한 줄 해석 문구 노출
- 홈에서 첫 인사이트 카드로 배치
- 카드 탭 시 반복지출 상세 목록으로 이동하거나 바텀시트를 여는 연결점

이번 기능에서 제외하는 것:

- 완전한 구독 관리 시스템
- 자동 해지 또는 액션 제안
- 이상지출 탐지
- AI 요약 문장 생성
- 교차 소스 검증 기반 고급 반복 판정

## 반복지출 정의

이번 기능에서 반복지출은 아래 세 부류를 다룬다.

### 1. 고정비

- 통신비
- 보험
- 월세
- 대출 상환
- 정기요금

특징:

- 거의 일정한 주기
- 비교적 일정한 금액
- 사용자가 쉽게 고정비로 인식하는 항목

### 2. 구독

- OTT
- 음악
- 앱 구독
- 멤버십

특징:

- 상호나 메모로 구독성 판단이 쉬운 경우가 많다
- 사용자가 줄일 후보로 가장 빠르게 떠올리는 영역이다

### 3. 반고정 생활비

- 비슷한 커피 지출
- 정기적 배달앱 사용
- 반복 택시
- 특정 편의점/쇼핑 루프

특징:

- 완전한 고정비는 아니지만 생활 습관처럼 반복된다
- 다정가계부가 다른 앱과 차별화되기 쉬운 영역이다

## 초기 판정 원칙

MVP에서는 `확실한 반복`만 먼저 보여준다.

초기 기준 예시:

- 동일 또는 유사한 상호/메모
- 최근 N일 안에 2회 이상 등장
- 금액이 완전히 같거나 허용 오차 안에 있음
- 간격이 유사함
- 텍스트 힌트에 구독/요금/보험/납부 등 반복성 단서가 있음

초기에는 아래 항목을 보수적으로 처리한다.

- 우연히 비슷한 두 번의 커피
- 일회성 쇼핑인데 금액이 비슷한 경우
- 동일 브랜드의 다른 목적 결제

즉 `더 많이 잡는 것`보다 `틀리지 않는 것`을 우선한다.

## 카드 구조

카드는 세 층으로 구성한다.

### 1. 총량

가장 먼저 보여줄 값:

- 이번 달 반복지출 총액

보조 값:

- 지난달 대비 증감
- 이번 달 전체 지출 중 비중

예시:

- 이번 달 반복지출 `312,000원`
- 지난달보다 `+28,000원`
- 전체 지출의 `24%`

### 2. 구성

상위 항목 3개를 보여준다.

우선순위는 아래 순서 중 하나를 사용한다.

- 금액 큰 순
- 새로 생긴 항목 우선
- 최근 발생 순

MVP 추천은 `금액 큰 순`이다.

예시:

- 보험 `86,000원`
- 통신비 `59,000원`
- 넷플릭스 `17,000원`

### 3. 해석

한 줄 해석 문구를 둔다.

예시:

- 이번 달 새로 잡힌 반복지출이 1건 있어요
- 지난달보다 반복지출이 조금 늘었어요
- 생활비보다 고정비 비중이 더 커졌어요

핵심은 경고가 아니라 설명이다.

## 문구 톤

피해야 할 톤:

- 과소비입니다
- 줄여야 합니다
- 낭비가 많습니다

권장 톤:

- 반복적으로 나가는 돈이 이만큼 있어요
- 지난달보다 조금 늘었어요
- 새로 보이는 정기성 지출이 있어요

즉 `훈계형`이 아니라 `확인형`이어야 한다.

## 홈에서의 위치

이 카드는 홈 첫 인사이트 블록으로 들어간다.

권장 순서:

1. 반복지출 인사이트 카드
2. 월간 수입/지출 스트립
3. 오늘 흐름 또는 최근 거래
4. 카테고리/예산 섹션

이 순서를 쓰는 이유:

- 첫 보상은 반복지출 발견
- 두 번째 보상은 익숙한 가계부 숫자
- 세 번째 이후는 운영과 회고

## 상세 진입

카드 탭 시 최소한 아래 중 하나로 이어져야 한다.

- 반복지출 목록 바텀시트
- 반복지출 상세 화면

MVP에서는 바텀시트가 더 적합하다.

보여줄 항목:

- 총액
- 항목 목록
- 최근 발생일
- 반복 유형 라벨: `고정비`, `구독`, `반고정`

이번 범위에선 편집/해지는 넣지 않는다.

## 데이터 요구사항

이 기능이 안정적으로 작동하려면 최소한 아래 필드가 필요하다.

- 거래 발생일
- 금액
- 거래 유형
- 상호 또는 메모
- 계정/결제수단 힌트
- 카테고리

추후 고도화에 필요한 데이터:

- 위치 힌트
- 원문 출처
- 신뢰도
- 사용자 교정 이력

## 성공 기준

이 기능이 잘 됐다고 볼 기준:

- 사용자가 홈 첫 화면에서 반복지출 총액을 즉시 이해한다
- 상위 3개 항목만으로도 줄일 후보를 떠올릴 수 있다
- 카드 문구가 훈계처럼 느껴지지 않는다
- 반복지출 카드가 기존 월간 수입/지출보다 더 먼저 눈에 들어온다
- 잘못 묶인 항목이 과하게 보이지 않는다

## 실패 신호

- 사용자가 카드를 단순 통계로만 본다
- 우연한 반복이 과하게 잡힌다
- 카드가 너무 길어져 첫 화면 집중도를 해친다
- 구독만 보이고 생활 속 반복소비는 전혀 안 잡힌다
- 카테고리 구조와 분리돼 가계부 같지 않게 느껴진다
