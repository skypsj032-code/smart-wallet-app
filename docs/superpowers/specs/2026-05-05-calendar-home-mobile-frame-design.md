# 홈 접이식 미리보기, 월간 달력 우선, 모바일 프레임 설계

## 요약

이번 변경의 목적은 기능을 빼는 것이 아니라, 홈과 달력의 첫 인상을 더 단순하게 만드는 것이다.

- 홈의 `달력`, `통계`는 기본으로 접혀 있다.
- 홈에서 `달력`을 열면 작은 월간 달력이 보인다.
- 홈에서 `통계`를 열면 상위 지출 카테고리 3줄이 보인다.
- 상세 조작은 각각의 전용 화면에서 한다.
- 달력은 진입 즉시 월간 달력이 먼저 보인다.
- 검색, 필터, 보기 전환은 손잡이를 당겼을 때만 열린다.
- 윈도우 앱은 모바일 세로형 프레임으로 고정한다.

핵심 원칙은 `홈은 축약형 미리보기`, `상세 화면은 실제 조작`이다.

## 목표

- 홈에서 달력과 통계를 찾기 쉽게 만들 것
- 홈이 기능 허브처럼 무거워지지 않게 할 것
- 달력 첫 화면이 탐색 UI보다 월간 달력을 먼저 보여주게 할 것
- 데스크톱에서도 모바일 앱처럼 보이게 할 것

## 정보 구조

### 홈

기존 홈의 `달력 / 통계` 진입 영역은 유지한다.

- 기본 상태는 접힘
- 펼치면 미리보기만 노출
- 각 카드 안에 `자세히 보기` 버튼 제공

달력 카드:
- 작은 월간 달력
- 오늘 건수
- 오늘 수입 / 지출
- `달력 크게 보기`

통계 카드:
- 이번 달 수입 / 지출
- 상위 지출 카테고리 3줄
- `통계 자세히 보기`

홈에서는 검색, 필터, 보기 전환을 노출하지 않는다.

### 달력

달력 화면의 첫 순서는 아래와 같다.

1. 상단 제목
2. 월간 달력
3. 선택한 날짜의 거래 목록

기본 숨김 요소:

- 주간 / 월간 / 연간 전환
- 검색
- 전체 / 수입 / 지출 필터

이 요소들은 상단 손잡이를 당겼을 때만 보인다.

### 통계

통계는 달력에서 바로 이어지지 않는다.

- 홈 또는 도구에서 진입
- 홈에서는 축약형 목록만 보여줌
- 상세 해석과 필터는 통계 화면에서 처리

## 상호작용

### 홈 접이식 카드

- 기본 상태는 닫힘
- 탭하면 펼쳐짐
- 펼쳐진 상태에서도 미리보기만 유지
- 더 자세한 조작은 상세 화면으로 이동해서 수행

### 달력 탐색 패널

- 기본 상태는 닫힘
- 손잡이만 보임
- 아래로 당기면 검색, 필터, 보기 전환이 나타남
- 닫으면 다시 월간 달력 중심 화면으로 돌아감

## 윈도우 프레임

- 모바일 세로 비율에 가깝게 고정
- 자유 리사이즈는 허용하지 않음
- 목적은 데스크톱에서도 일관된 단일 패널 경험 유지

## 테스트 기준

- 홈의 달력/통계 카드가 기본으로 접혀 있는지
- 달력을 펼쳤을 때 작은 월간 달력이 보이는지
- 통계를 펼쳤을 때 상위 카테고리 3줄이 보이는지
- 각 카드의 상세 진입 버튼이 살아 있는지
- 달력 진입 시 월간 달력이 먼저 보이는지
- 탐색 패널 요소가 기본 상태에서 숨겨지는지
- 윈도우 앱이 세로형 고정 프레임으로 실행되는지
