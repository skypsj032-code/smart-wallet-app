# Future Investment Expansion

Status: Backlog  
Date: 2026-05-05

This document captures postponed ideas related to stock and ETF expansion so
they do not get mixed into the current household-finance IA work.

## Intended feature areas

- stock recommendations
- ETF recommendations
- ranking surfaces
- security / ETF information summaries
- community features around each item

## Suggested rollout order

### 1. Discovery

- searchable stock / ETF list
- basic ranking views
- simple interest or popularity sorting

### 2. Detail

- security overview
- ETF composition summary
- dividend / yield / volatility style metadata

### 3. Personal relevance

- save 관심 종목
- lightweight watchlist behavior
- connect investment interests back to user money habits only if it feels
  natural

### 4. Community

- post or note per item
- reactions / comments
- sharing and discussion flows

## Boundaries for later planning

- do not merge this directly into the current wallet IA without a separate
  product decision
- treat market data, ranking freshness, and community moderation as first-class
  planning topics
- define whether this remains an offline-first personal finance app or expands
  into a connected investment product before implementation begins
