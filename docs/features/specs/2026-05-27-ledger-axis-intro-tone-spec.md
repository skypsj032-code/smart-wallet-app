- Why: `달력 / 통계 / 자산` 화면은 이동 구조는 맞춰졌지만, 들어가자마자 보이는 첫 카드의 톤은 아직 제각각이다. 같은 가계부 기본 축처럼 느껴지게 하려면 공통된 첫인상이 필요하다.
- Change: 세 화면 상단에 공통 톤의 축 소개 카드를 추가해, 각 화면이 무엇을 보여주는지 짧고 일관된 문장으로 먼저 설명한다.
- Scope:
  - `CalendarScreen`
  - `StatisticsScreen`
  - `AccountsScreen`
  - shared intro widget
- Tone:
  - 설명형
  - 과한 해석보다 기능적 안내 우선
  - 편한가계부처럼 `들어오면 무엇을 볼 수 있는지`가 바로 느껴지게
- Out of scope: 기존 상세 카드 로직 변경, 라우트 구조 변경, 차트/캘린더/계좌 목록 재설계.
