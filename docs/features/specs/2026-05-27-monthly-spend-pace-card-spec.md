# Monthly Spend Pace Card

- 왜: 반복지출 다음에 `이번 달이 지금 어떤 속도로 흘러가는지`를 한 문장으로 보여줘서, 편한가계부처럼 홈을 열자마자 월간 상태를 이해하는 보상을 준다.
- 변화: 홈 상단에 `이번 달 소비 페이스` 카드가 생기고, 현재 지출 속도를 바탕으로 월말 예상 지출과 예산 대비 상태를 설명형으로 보여준다.
- 범위: 대시보드 summary에 소비 페이스 계산 모델을 추가하고, 홈에서 반복지출 카드 다음에 소비 페이스 카드를 노출한다.
- 비범위: 카테고리별 과소비 분석, 이상지출 탐지, 예산 편집 진입, 새 통계 화면 추가.

## 기대 경험

- 사용자는 홈을 열자마자 `이번 달은 괜찮은지`, `조금 빠른지`, `예산을 넘길 가능성이 있는지`를 한눈에 이해한다.
- 카드 문구는 훈계형이 아니라 설명형으로 유지한다.
- 예산이 없는 경우에도 카드는 사라지지 않고, 현재 속도를 바탕으로 월말 예상 지출을 보여준다.

## 정보 구조

- 헤더: `이번 달 소비 페이스`
- 상태 한 줄:
  - 안정: `지금 속도면 이번 달도 무리 없이 가고 있어요`
  - 주의: `지출 속도가 조금 빠른 편이에요`
  - 초과 위험: `이 속도면 이번 달 예산을 넘길 수 있어요`
  - 예산 없음: `이달 지출 흐름을 기준으로 월말 예상치를 잡아봤어요`
- 보조 설명:
  - `오늘은 31일 중 15일째`
  - `지금까지 240,000원`
  - `이 속도면 약 496,000원`
- 보조 배지:
  - 예산이 있으면 `예산 대비 99% 예상`
  - 예산이 없으면 `월말 예상 지출`

## 판정 기준

- 입력값:
  - 이번 달 누적 지출
  - 이번 달 예산 총액
  - 현재 날짜
- 계산:
  - `elapsedDays = now.day`
  - `daysInMonth = 이번 달 총 일수`
  - `monthProgress = elapsedDays / daysInMonth`
  - `projectedMonthExpense = monthExpense / monthProgress`
- 상태:
  - 예산 없음: `noBudget`
  - 예상 사용률 `< 90%`: `steady`
  - 예상 사용률 `>= 90%` and `< 105%`: `watch`
  - 예상 사용률 `>= 105%`: `overspending`

## 적용 원칙

- 반복지출 카드보다 아래, 기존 예산 상태 카드보다 위에 둔다.
- 홈 상단 보상은 `반복적으로 새는 돈`과 `이번 달 속도 이해`의 2축으로 만든다.
- 예산 상태 카드는 상세 압박 확인용으로 남기고, 새 카드는 번역된 보상 문구 역할을 맡는다.
