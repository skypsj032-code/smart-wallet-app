- 왜: `반복 아님`으로 제외한 항목을 다시 살리는 경로가 없어서 반복지출 기능이 반쪽으로 남아 있다.
- 변화: 반복지출 목록 바텀시트 안에서 `제외된 항목 n개`를 열고, 항목별로 반복지출 해석에 다시 포함시킬 수 있다.
- 범위: 기존 반복지출 흐름 안의 복구 진입점, 제외 항목 목록, `반복 아님` 해제 액션.
- 비범위: 별도 설정 화면, 숨김 기능, detector 규칙 자체의 사용자 편집.
- 원칙: 잘되는 가계부들처럼 보정 액션은 상세/옵션 흐름에 두되, 복구 경로는 현재 반복지출 문맥 안에서 바로 찾을 수 있어야 한다.
