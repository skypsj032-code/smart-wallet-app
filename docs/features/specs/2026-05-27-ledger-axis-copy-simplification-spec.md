- Why: `달력 / 통계 / 자산` 화면의 구조는 가까워졌지만, 섹션 제목과 버튼 문구는 아직 설명형 표현이 많다. 편한가계부처럼 도구적인 화면 문법에 더 가깝게 가려면 라벨이 짧고 즉시 이해되어야 한다.
- Change: 세 화면의 섹션 제목과 보조 액션 문구를 더 짧고 기능적인 표현으로 정리한다.
- Direction:
  - `보는 방식` -> `보기`
  - `이번 흐름` -> `요약`
  - `핵심 숫자` -> `숫자`
  - `카테고리 해석` -> `카테고리`
  - `바로 이어보기` -> `이동`
  - `차트는 참고` -> `차트`
  - `거래 바로 입력` -> `입력`
  - `달력 보기 / 내역 보기 / 통계 보기` -> `달력 / 내역 / 통계`
- Out of scope: 본문 설명 문장 전체 재작성, 카드 구조 변경, 로직 변경.
