- Change: 홈 상단에 가계부 기본 축 바로가기 구간을 추가해 `달력`, `통계`, `자산` 화면으로 즉시 이동할 수 있게 한다.
- Placement: overview hero와 월간 수입/지출 strip 다음, 예산 흐름 전에 둔다.
- Behavior:
  - `달력`은 `/calendar`
  - `통계`는 `/statistics`
  - `자산`은 `/accounts`
- Tone: 분석 카드보다 더 중립적이고 기능적인 톤으로 유지한다.
- Out of scope: 새 화면 추가, 기존 라우트 구조 변경, 각 화면 내부 개편.
