# Compact Recent Transactions Section

- 왜: 홈 상단 보상 카드가 충분히 생긴 뒤에는 `최근 거래`가 긴 리스트보다 `마지막 확인 패널`에 가까워야 더 빠르게 읽힌다.
- 변화: 홈 `최근 거래` 섹션은 최근 3건만 보여주고, 아래에서 `전체 보기`로 타임라인으로 이어진다.
- 범위: 대시보드의 `_RecentTransactionsSection`만 압축한다.
- 비범위: 타임라인 화면 변경, 거래 상세 화면 추가, 필터 기능.

## 적용 원칙

- 최근 거래는 홈의 핵심 보상이 아니라 마지막 점검 역할이다.
- 홈에선 `최근 3건`만 보여준다.
- 나머지 확인은 `전체 보기`로 타임라인에 넘긴다.
- 빈 상태 문구는 유지한다.
