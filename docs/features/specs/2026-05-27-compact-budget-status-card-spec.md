# Compact Budget Status Card

- 왜: 홈 상단 보상 카드가 4개로 늘어나면서 기존 `예산 상태` 카드가 중복되고 무거워졌다. 이 카드는 이제 핵심 보상보다는 보조 확인 패널 역할이 더 맞다.
- 변화: 대시보드 하단 `예산 상태` 카드를 큰 헤드라인 중심에서 `진행률 + 남은 예산 + 짧은 설명` 중심의 컴팩트 카드로 압축한다.
- 범위: `dashboard_screen.dart` 의 `_BudgetStatusCard` 레이아웃과 문구를 줄인다.
- 비범위: 예산 계산 로직 변경, 예산 편집 진입, 새 예산 화면.

## 변경 원칙

- 홈 상단의 핵심 보상은 새 카드 4종이 맡는다.
- 예산 상태 카드는 `빠르게 한번 더 확인하는 패널`이 된다.
- 기존처럼 큰 headline 하나를 내세우지 않고:
  - 진행률
  - 남은 예산
  - 한 줄 해석
  를 먼저 보여준다.

## 기대 결과

- 홈을 아래까지 내려도 정보 밀도가 과하지 않다.
- 예산 상태는 남아 있지만 앞선 카드와 역할이 덜 겹친다.
- 편한가계부처럼 많은 정보를 보여주되, 위계는 더 분명해진다.
