- Why: 홈에서 `달력 / 통계 / 자산` 기본 축으로 진입할 수 있게 됐지만, 각 화면 안에서는 다시 서로 오가는 감각이 약하다. 편한가계부처럼 기본 축이 제품 전반에서 이어져야 한다.
- Change: `달력`, `통계`, `자산` 화면 상단에 공통 축 이동 구간을 추가해 서로 바로 이동할 수 있게 한다.
- Behavior:
  - 현재 화면 축은 강조 표시하고 비활성처럼 보이게 한다.
  - 다른 축은 탭 시 기존 라우트로 이동한다.
  - 공통 톤은 설명 카드보다 기능적이고 중립적으로 유지한다.
- Scope:
  - `CalendarScreen`
  - `StatisticsScreen`
  - `AccountsScreen`
- Out of scope: 각 화면의 핵심 카드 재설계, 하단 내비게이션 변경, 새 라우트 추가.
