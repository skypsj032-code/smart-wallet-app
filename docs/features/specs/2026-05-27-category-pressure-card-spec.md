# Category Pressure Card

- 왜: 홈에서 `어디가 제일 크고 조심해야 하는지`를 바로 보여줘서, 편한가계부식 카테고리 확인 보상을 추가한다.
- 변화: 홈 상단에 `카테고리 압박` 카드가 생기고, 예산이 있는 사용자는 가장 압박이 큰 카테고리를, 예산이 없는 사용자는 가장 많이 쓴 카테고리를 보여준다.
- 범위: 기존 `BudgetSummary`를 바탕으로 카테고리 압박 인사이트를 계산하고, 홈에서 카드로 노출한다.
- 비범위: 카테고리 상세 화면, 통계 차트, 이상지출 탐지, 새 예산 편집 흐름.

## 판정 규칙

- 우선순위 1: `categoryId != null` 이고 `limitAmount > 0` 인 항목 중 `progress`가 가장 높은 항목
- 우선순위 2: 위 조건이 없으면 `spentAmount`가 가장 큰 카테고리 항목
- 제외:
  - `categoryId == null` 인 전체 예산 항목
  - `spentAmount == 0` 인 항목

## 정보 구조

- 헤더: `카테고리 압박`
- 상태 문구:
  - 예산 기준 `progress >= 1.0`: `이번 달은 {카테고리}가 가장 빠르게 커졌어요`
  - 예산 기준 `progress >= 0.8`: `이번 달은 {카테고리}를 조금 더 자주 보게 될 것 같아요`
  - 예산 기준 `progress < 0.8`: `이번 달은 {카테고리}가 가장 크게 나가고 있어요`
  - 예산 없음: `이번 달은 {카테고리}가 가장 크게 나가고 있어요`
- 보조 정보:
  - 지출 금액
  - 예산이 있으면 `예산 대비 n%`
  - 예산이 없으면 `이번 달 최다 지출 카테고리`

## 적용 원칙

- 홈 보상 흐름은 `반복적으로 나가는 돈 -> 이번 달 소비 페이스 -> 곧 나갈 돈 -> 카테고리 압박` 순서로 둔다.
- 편한가계부식 확인 보상을 가져오되, 문구는 훈계형이 아니라 설명형으로 유지한다.
- 예산을 아직 안 쓰는 사용자도 빈 카드 없이 카테고리 보상을 받게 한다.
