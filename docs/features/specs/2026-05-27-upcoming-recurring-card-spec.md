# Upcoming Recurring Card

- 왜: 반복적으로 나가는 돈과 이번 달 소비 페이스 다음에 `곧 나갈 돈`을 보여줘서, 편한가계부와 Rocket Money류 앱처럼 홈에서 가까운 미래의 지출까지 한 번에 확인하게 만든다.
- 변화: 홈 상단에 `곧 나갈 돈` 카드가 추가되고, 반복지출 중 다음 예상 시점이 가까운 항목 2~3개를 날짜순으로 보여준다.
- 범위: 반복지출 그룹에서 `fixed / subscription` 성격의 upcoming 항목을 뽑아 홈 카드에 노출한다.
- 비범위: 캘린더 화면, 청구일 수동 수정, lifestyle 반복소비의 미래 예측, 알림 기능.

## 정보 구조

- 헤더: `곧 나갈 돈`
- 설명: `다음 결제 흐름을 먼저 확인해둘게요.`
- 항목 정보:
  - 이름
  - 다음 예상 날짜
  - 이번 달 기준 금액
- 정렬:
  - `nextExpectedDate` 오름차순
  - 같으면 금액 큰 순

## 노출 규칙

- `RecurringSpendKind.fixed`, `RecurringSpendKind.subscription`만 기본 노출
- 최대 3개
- upcoming 후보가 없으면 카드 전체를 숨긴다
- lifestyle 반복소비는 향후 날짜 신뢰도가 낮아서 홈 upcoming 카드에서는 제외한다

## 인터랙션

- 카드 전체 탭: 기존 반복지출 목록 바텀시트를 연다
- 개별 항목 탭: 이번 단계에서는 별도 액션 없이 카드 전체 탭만 유지한다

## 적용 원칙

- 홈 상단 보상 흐름을 `반복적으로 나가는 돈 -> 이번 달 소비 페이스 -> 곧 나갈 돈` 순서로 만든다.
- 문구는 훈계형이 아니라 확인형으로 유지한다.
- `곧 나갈 돈`은 통계가 아니라 일정 확인 보상이다.
