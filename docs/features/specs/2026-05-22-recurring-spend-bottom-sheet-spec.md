# Recurring Spend Bottom Sheet Spec

작성일: 2026-05-22  
기능 slug: `recurring-spend-bottom-sheet`  
기능 크기: `medium`  
상태: draft

## 왜 하는가

- 홈의 반복지출 카드는 첫 보상을 만든다.
- 그 다음에는 사용자가 `정확히 무엇이 반복지출로 잡혔는지`를 빠르게 확인할 수 있어야 한다.
- 이 확인 단계가 없으면 카드가 해석처럼 보여도 신뢰가 약해진다.

## 문제 정의

- 현재 홈 카드는 총액, 상위 3개, 한 줄 해석만 보여준다.
- 사용자는 카드만 보고는 전체 반복지출 목록, 최근 발생 시점, 새로 보이는 항목을 충분히 확인할 수 없다.
- 따라서 카드 탭 이후의 첫 상세 계층이 필요하다.

## 경쟁 제품 기준

반복지출 목록의 기본 정렬은 우리 추정보다 `이미 잘되는 가계부의 정보 문법`을 우선한다.

- `편한가계부`는 반복/할부를 가계부 흐름 안의 예정 내역으로 다룬다.
- `Rocket Money`는 `Recurring` 기본값을 `Upcoming`으로 두고 날짜순으로 보여준다.
- `Monarch`도 recurring을 calendar/review 흐름으로 본다.
- `Copilot`은 recurring을 현금흐름 해석에 묶지만, 결국 시간성과 예정성 문법이 강하다.

따라서 반복지출 상세 목록의 기본 정렬은 `금액순`이 아니라 `시간순`이어야 한다.

## 제품 원칙

- 기본 축은 `시간성`이다.
- 보조 축은 `영향도`다.
- 사용자는 먼저 `무엇이 곧 이어지는지`를 보고,
  그 다음에 `무엇이 큰지`와 `무엇이 새로 생겼는지`를 이해한다.
- 이 화면은 훈계가 아니라 확인 화면이다.

## 사용자 변화

기존:

- 반복지출 카드에서 일부 항목만 본다.
- 전체 반복지출 흐름은 아직 알기 어렵다.

변경 후:

- 카드 탭으로 반복지출 전체 목록을 본다.
- 어떤 항목이 새로 보였는지, 어떤 항목이 곧 이어질지, 어떤 항목이 큰지 같이 이해한다.

## 범위

이번 기능에 포함:

- 반복지출 카드 탭 액션
- 반복지출 전체 목록 바텀시트
- 기본 정렬: `다가오는 순서`
- 보조 정보: 이번 달 금액, 유형, 지난달 대비, 최근 결제일
- 상단 요약: 총액과 보조 설명
- 별도 섹션: `새로 보이는 반복지출`

이번 기능에서 제외:

- 반복지출 전용 전체 화면
- 항목 수정/숨김/제외 액션
- 구독 해지 제안
- AI 요약 생성
- 고급 필터와 정렬 변경 UI

## 정보 구조

바텀시트는 아래 순서로 구성한다.

### 1. 헤더 요약

- 제목: `반복적으로 나가는 돈`
- 보조 문구: 이번 달 반복지출 총액과 짧은 설명
- 닫기 액션

### 2. 새로 보이는 반복지출

조건:

- `previousMonthAmount == 0`
- 이번 달에 보이는 반복지출 그룹

역할:

- 사용자가 가장 먼저 새 변화를 보게 한다.
- 기본 정렬은 최근 발생일 역순으로 둔다.

표시 정보:

- 이름
- 유형
- 이번 달 금액
- `이번 달 새로 보였어요` 보조 문구

### 3. 전체 반복지출 목록

기본 정렬:

- `다가오는 순서`

초기 버전에서 `다가오는 순서`는 아래 대리 규칙으로 계산한다.

- 각 그룹의 가장 최근 거래일을 찾는다.
- 고정비/구독처럼 월간 반복이면 `최근 거래일 + 1개월`을 다음 시점으로 본다.
- 생활 반복지출은 예정 정확도가 낮으므로 `최근 거래일` 기준의 가까운 순서로 둔다.
- 다음 시점을 정확히 계산할 수 없으면 최근 거래일이 더 최신인 항목을 위에 둔다.

보조 정렬:

- 다음 시점이 같으면 이번 달 금액 큰 순
- 그래도 같으면 이름 오름차순

표시 정보:

- 이름
- 유형
- 이번 달 금액
- 지난달 대비 증감 또는 동일 여부
- 최근 결제일 또는 다음 예상 시점

## 정렬 기준을 이렇게 두는 이유

- 잘되는 가계부들은 반복지출을 `시간 흐름 안의 예정 돈`으로 보여준다.
- 금액순은 통계 문법에는 맞지만, 반복지출 상세의 기본 문법으로는 덜 맞다.
- 사용자는 이 화면에서 `무엇이 큰가`보다 `무엇이 또 이어지나`를 더 자주 확인한다.
- 다만 영향도도 중요하므로 금액은 보조 정렬과 표시 정보로 유지한다.

## 문구 톤

피해야 할 톤:

- `과소비입니다`
- `줄여야 합니다`
- `낭비가 많습니다`

권장 톤:

- `이번 달에도 이어지는 지출이 보여요`
- `새로 보이는 반복지출이 있어요`
- `지난달보다 조금 늘었어요`
- `곧 다시 이어질 수 있는 지출부터 보여드릴게요`

## 데이터 요구사항

이미 있는 데이터로 우선 구성한다.

- `displayName`
- `kind`
- `currentMonthAmount`
- `previousMonthAmount`
- `transactions`

바텀시트 계산에 추가로 필요한 값:

- 각 그룹의 최근 거래일
- 각 그룹의 다음 예상 시점
- 증감 상태 문구

위 값은 detector 결과를 확장하거나 presentation 조립 단계에서 계산할 수 있다.

## 리스크

- 생활 반복지출은 `다가오는 순서`를 정확히 예측하기 어렵다.
- 최근 거래일 기반 정렬은 완전한 청구일 정렬보다 덜 정확하다.
- 하지만 초기에는 `잘되는 가계부의 시간 문법`을 먼저 따르는 것이 더 중요하다.

## 성공 기준

- 사용자가 홈 카드 탭 후 전체 반복지출 흐름을 바로 이해할 수 있다.
- 새로 보이는 반복지출이 눈에 띄게 분리된다.
- 목록의 기본 순서가 금액 통계보다 `이어질 흐름`처럼 느껴진다.
- 화면이 훈계형이 아니라 확인형 도구로 읽힌다.
