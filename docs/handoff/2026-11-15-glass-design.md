# 가계부 글래스 디자인 작업 인계

## 현재 상태

- 이 브랜치는 자동 알림 감지와 영수증 검토 등이 포함된 통합 초안 `codex/wallet-integration-draft-20261113`의 `2f7c7b6313ca5b38875d59aa6f0fb2a54da7a35a`에서 시작했다.
- Work 모드에서 수정 중이던 날씨형 글래스 디자인 소스 11개 파일을 2026-11-15에 스냅샷으로 옮겼다. 하늘색 테마, 반투명 카드, 홈 화면과 입력 흐름 변경이 포함된 **미완성 작업**이다.
- 알림 권한이 없는 수동 시험판의 Android 매니페스트, 라우터, 설정 화면, 도구 화면과 그 전용 테스트는 가져오지 않았다. 통합 초안의 원래 파일을 유지했다. 실제 자동 감지 동작은 이 스냅샷에서 다시 확인해야 한다.
- 이 스냅샷을 옮긴 환경에는 Flutter SDK가 없어 빌드와 Flutter 테스트를 실행하지 못했다. 이전 버전의 테스트 성공은 이 스냅샷의 검증 결과가 아니다.
- 기존 수동 시험판은 PR #6, 자동 감지 통합 초안은 PR #4에 남아 있다. 이 브랜치를 곧바로 완성품이나 배포판으로 취급하지 않는다.

## 이어서 할 일

1. 작업할 컴퓨터의 저장소와 로컬 수정 사항을 먼저 확인하고 보존한 뒤, 이 브랜치를 별도 작업 공간에서 연다.
2. Flutter 의존성과 생성 코드를 준비하고 `flutter analyze`와 기존 테스트를 실행해 글래스 작업의 컴파일 오류와 회귀를 확인한다.
3. 홈부터 기록 저장까지 실제 사용자 흐름이 자연스럽게 이어지는지 살펴보고 날씨 앱처럼 일관된 반투명 글래스 디자인으로 완성한다.
4. 알림 확인 후 기록, 직접 입력, 영수증 검토, 백업과 복원 등 기존 기능이 유지되는지 점검한다. 특히 기록 저장과 기존 데이터 보존을 확인한다.
5. 작은 화면, 큰 글씨, 어두운 화면과 실제 Android 기기에서 확인한 뒤 결과와 남은 문제를 기록한다.

임시 시험판의 별도 앱 ID 및 서명은 기존 설치 앱의 데이터와 다를 수 있다. 설치와 데이터 이전 여부를 확인하기 전에는 기존 데이터를 자동으로 이어받는다고 안내하지 않는다.
